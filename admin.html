Parish website

Prepare Sunday updates.

Enter the Sunday theme, readings, and announcements. Download the update file, then replace data/parish-updates.json in the website project and push the change to GitHub to publish it.

How publishing works: This parish website is hosted as static files, so this editor cannot publish directly or provide secure sign-in. It saves drafts only in this browser and downloads a file for you to add to the project before committing and pushing. The editor page itself is not password protected, so do not enter private information.
